Cómo leer el ranking

Una clasificación explicada, no un número arbitrario

La puntuación general de esta página es una evaluación editorial para comparar productos de propósito general. No sustituye los resultados de laboratorios independientes. Cuando existe una métrica independiente reciente, también se muestra por separado.

Qué significa “mejor” aquí

Se valora la capacidad para resolver tareas complejas, programar, investigar, trabajar con distintos tipos de contenido, utilizar herramientas, ejecutar flujos de varios pasos y ofrecer un producto útil para usuarios reales. Una puntuación alta no significa que gane en cada categoría.

Infraestructura frente a aplicación

Quién construye la inteligencia y quién construye sobre ella

Una aplicación conocida puede ser excelente aunque no entrene su propio modelo. Esta separación ayuda a entender la cadena tecnológica real.

1. Cómputo y centros de datosChips, aceleradores, redes, centros de datos y capacidad de entrenamiento.
2. Modelos fundacionalesModelos entrenados por organizaciones como OpenAI, Anthropic, Google, Alibaba, Meta o DeepSeek.
3. Plataformas y acceso para desarrolladoresServicios que permiten integrar los modelos en productos, agentes y procesos empresariales.
4. Aplicaciones finalesProductos como asistentes, editores de código, diseño, presentaciones, automatización y educación.
