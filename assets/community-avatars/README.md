# Avatares de la comunidad

Esta carpeta está reservada para las imágenes de perfil del chat y de los debates de AI World Atlas.

## Criterios

- Personajes divertidos, excéntricos y con personalidad.
- Apariencia adulta, no infantil.
- Variedad real de rostros, peinados, estilos y expresiones.
- Evitar imágenes repetidas o demasiado parecidas.
- Preferencia por formato cuadrado 1:1.
- Recomendado: PNG, WebP o JPG.
- Ideal: al menos 512 × 512 px.

## Convención sugerida

`avatar-001.webp`
`avatar-002.webp`
`avatar-003.webp`

Cuando tengamos una colección suficiente, se asignarán de forma estable a los apodos del chat y los debates.
